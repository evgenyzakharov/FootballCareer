# Своя карьера — иммерсивный симулятор футбольной карьеры

Текстовый симулятор карьеры футболиста: от академии в 16 лет до последнего сезона.
Сделан по идее [copero.com.ar/juegos/simulador-carrera](https://copero.com.ar/juegos/simulador-carrera),
но с другой ставкой: там сезон — чёрный ящик и 8–24 решения за карьеру, здесь сезон
разбит на шесть этапов и решений выходит **200–260 за карьеру**.

```bash
npm install
npm run dev
```

Прочее: `npm run build`, `npm test`, `npm run lint`,
`npx tsx scripts/balance.ts 80` — диагностика баланса.

## Чем отличается от референса

Референс разобран по его публичному JS-бандлу (`assets/CareerSimulatorPage-*.js`).
**Цифры по референсу — результат чтения минифицированного кода и требуют проверки,
если на них надо опираться.**

| | Референс | Здесь |
|---|---|---|
| Решений за карьеру | 8–24 (одно на 1–3 сезона) | 200–260 |
| Структура сезона | одна карточка, остальное авто | 6 этапов: предсезонка → первая половина → зимнее окно → вторая половина → концовка → итоги |
| Уровень игрока | один OVR | 8 навыков + позиционные веса → OVR; скорость садится раньше, чтение игры растёт дольше |
| Состояние | нет | форма, свежесть, настрой, доверие тренера, трибуны, пресса, раздевалка, известность |
| Люди | нет | тренер (со стилем и увольнениями), агент, конкурент за место, капитан, наставник, журналист — у каждого своё отношение |
| Последствия | событие сработало и забылось | отложенные последствия через 1–8 сезонов (`Consequence`) |
| Ключевые матчи | один «решающий пенальти» | проверки по конкретным навыкам: удар, передача, дриблинг, характер |
| Ситуаций | 29 | 60 |
| Травмы | один бросок | 13 видов, три степени, выбор восстановления, рецидивы, хроника |
| Языки | ES / EN / PT | RU / EN (ключи + обе локали рядом в одном файле) |

## Как это устроено

Движок — чистые функции без React. Состояние сериализуемо, RNG восстанавливается
из `(seed, метка, шаг)`, поэтому карьера воспроизводима один в один и на неё
пишутся тесты.

```
src/
  engine/
    types.ts         все типы домена
    rng.ts           детерминированный RNG из (seed, label, step)
    attributes.ts    веса позиций, OVR, возрастные кривые, цена игрока
    player.ts        создание игрока, уровень состава, развитие
    performance.ts   роль в клубе, симуляция игрового блока, оценки
    competitions.ts  трофеи клуба и сборной
    awards.ts        индивидуальные награды
    relationships.ts NPC: стиль тренера, увольнения, давление конкурента
    offers.ts        генерация предложений и условий контракта
    career.ts        машина сезона: этапы, биты, применение эффектов
    save.ts          localStorage
    events/          60 событий по каналам + структурные карточки
  data/              клубы, лиги, страны, пулы фамилий
  i18n/              t() + content/*.ts — ru и en в одном файле
  ui/                React-компоненты
```

### Машина сезона

`state.queue` держит **биты**, а не готовые карточки. Карточка собирается в
момент показа — поэтому она видит эффекты всех предыдущих решений этого этапа.

```
preseason  новый тренер? → задача на сезон → 1–2 события
autumn     вызов в сборную? → 1–2 события → бросок травмы → отыгрыш блока
winter     1–2 события (трансферы, контракт, жизнь)
spring     событие → бросок травмы → отыгрыш блока
run_in     ключевой матч
review     турнир сборной? → итоги сезона → трансферное окно
```

Трансферное окно открывается не каждое лето (`marketIsOpen`): иначе карьера
превращается в список городов. С контрактом в силе и без желания уйти — 18%.

### Как добавить событие

Одного файла достаточно: определение в `src/engine/events/*.ts` и тексты в
`src/i18n/content/events-*.ts`.

```ts
{
  key: 'agent_dinner',
  channel: 'transfer',
  stages: ['winter'],
  once: false,
  weight: 5,
  when: (c) => c.player.age >= 22,
  build: () => ({ options: [{ id: 'go', hints: [H.moneyUp, H.gamble] }, { id: 'skip', hints: [H.safe] }] }),
  resolve: (c, id) =>
    id === 'go'
      ? { outcome: 'ok', effects: [money(200_000), rel('agent', 10)], tone: 'good' }
      : { outcome: 'skip', effects: [] },
}
```

Ключи текстов складываются по соглашению: `ev.<key>.title`, `.body`,
`.opt.<id до двоеточия>`, `.res.<outcome>`, `.hl.<outcome>` для строки в ленте
новостей. Подсказки на кнопках берутся из общего словаря `H` — их около 35,
и они переиспользуются везде, чтобы i18n не разрастался.

Тест `tests/career.test.ts` прогоняет десять карьер, рендерит каждую карточку в
обеих локалях и падает, если встретился ключ без перевода. Отдельной сверки
словарей не нужно.

## Данные о клубах

~236 клуба, 20 лиг, 49 национальностей. **Тир клуба (0–5) — игровая величина,
а не факт**: он задаёт уровень состава, шансы на трофеи и планку ожиданий.
Значения расставлены на глаз под баланс и правятся в одном месте —
`src/data/clubs.ts`. Названия лиг и кубков внутри симуляции обобщены
(«Главный еврокубок» вместо официального названия).

Названия клубов используются только для идентификации внутри симуляции;
дисклеймер выведен в подвале приложения, как в референсе.

## Баланс

`npx tsx scripts/balance.ts 80` гоняет карьеры со **случайными** выборами —
это нижняя граница, живой игрок выжимает больше. Текущий разброс:

| | мин | p25 | среднее | p75 | макс |
|---|---|---|---|---|---|
| сезонов | 18 | 18 | 20.1 | 21 | 25 |
| возраст ухода | 34 | 34 | 36.1 | 37 | 41 |
| пик OVR | 72 | 77 | 79.7 | 82 | 89 |
| клубов | 5 | 8 | 9.3 | 11 | 16 |
| матчей | 67 | 144 | 260 | 368 | 723 |
| трофеев | 0 | 4 | 6.1 | 8 | 17 |
| вызовов в сборную | 0 | 28 | 65.5 | 102 | 151 |

Где крутить: базовые шансы на трофеи — `engine/competitions.ts` (`ODDS`),
пороги наград — `engine/awards.ts`, темп роста — `engine/attributes.ts`
(`AGE_BANDS`, `PEAK_OFFSET`) и `growthFactor` в `engine/career.ts`,
минуты и оценки — `engine/performance.ts`.

## Проверка

- `npm test` — 7 тестов: сквозные карьеры, детерминизм по сиду, границы
  статистики, полнота обеих локалей.
- `scripts/dom-check.js` — драйвер для проверки интерфейса в headless-браузере:
  щёлкает от интро до пенсии и складывает отчёт в `<pre id="TESTOUT">`.
  На этой машине панель браузера не используется, поэтому проверка идёт по DOM.

Что уже не сделано и стоит следующим шагом: шареабельная карточка итогов карьеры
и ачивки (в референсе их 24) — в движке для этого уже есть `flags`, `trophies` и
`awards`, нужна только надстройка.
